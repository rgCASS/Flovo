05

Your logic, one trait away

Implement BaseNode, register a factory, and keep domain behavior in your application.

10 lines

to describe the execution surface of a custom node.

Read the full API ↗
audit_node.rs
#[async_trait]
impl BaseNode for AuditNode {
    fn name(&self) -> &str { "audit" }
    fn node_type(&self) -> NodeType { NodeType::Step }
    fn choices(&self) -> &[String] { &[] }
    async fn run(&self, _ctx: &NodeContext) -> Result<()> { Ok(()) }
}
